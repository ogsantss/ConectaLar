# 🧹 DiaristaApp

App para diaristas gerenciarem solicitações de serviço, tipo uma rede/marketplace entre cliente e diarista.

## 📋 O que o app faz

* Cliente solicita um serviço de limpeza
* Diarista visualiza e aceita ou recusa a solicitação
* Fluxo simples de agendamento entre as duas partes

## 🛠️ Tecnologias

* Java
* Spring Boot
* HTML
* CSS
